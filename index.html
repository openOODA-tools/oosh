🐚 Safe Default Login Shell Configuration

Configure oosh as your primary interactive shell safely across standard distributions, encrypted systemd-homed environments, or user-local installations.

Standard Linux (chsh)

For system-wide installs in /usr/local/bin or /usr/bin:

chsh -s /usr/local/bin/oosh
systemd-homed (homectl)

For encrypted LUKS per-user homes managed by systemd-homed:

homectl update "$USER" --shell=/usr/local/bin/oosh
Safe Interactive Exec Chaining (~/.bashrc)

Essential for user-local installs (~/.local/bin/oosh) and encrypted homes: prevent SSH lockout by keeping /bin/bash as your login shell and chaining into oosh at the end of ~/.bashrc:

if [[ $- == *i* ]] && [ -x /usr/local/bin/oosh ] && [ "$OOSH_ACTIVE" != "1" ]; then export OOSH_ACTIVE=1 exec /usr/local/bin/oosh fi
